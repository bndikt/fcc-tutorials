2. Generation and Fast Simulation

If you want to get started with generation and a first quick inspection of fast-simulated events, you’re at the right place. This chapter focuses on the generation of samples. A more in-depth look at FCCAnalyse is given in the next chapter.

Fast simulation is currently supported through the Delphes approach. Support for the Papas approach, initially used for FCC-ee, is discontinued.

If you have any problems or questions, you can open an issue on the GitHub repository where these lessons are developed.
